# K230: DM Code / Data Matrix Recognition

Эта папка содержит демонстрационные примеры для **Yahboom K230 Vision Module** по теме распознавания **DM code / Data Matrix**. Камера K230 получает изображение, ищет Data Matrix через `img.find_datamatrices()`, извлекает `payload`, определяет угол поворота и показывает результат на экране.

DM code, или Data Matrix, — это двумерный код из черных и белых элементов. Он часто используется в промышленной маркировке, трассировке маленьких деталей и задачах, где код должен занимать небольшую площадь.

## Файлы

| Файл | Назначение |
| --- | --- |
| `01_dmcode_recognition.py` | Базовая демонстрация: поиск Data Matrix, рамка, payload, rotation и FPS. |

## Быстрый старт

1. Сгенерируйте DM code / Data Matrix. Можно использовать генератор из материалов Yahboom или онлайн-генератор.
2. Откройте `01_dmcode_recognition.py` в CanMV IDE.
3. Подключите K230 к компьютеру по USB.
4. Запустите скрипт.
5. Наведите камеру на DM code так, чтобы он был крупным, ровным и в фокусе.
6. На экране появится красная рамка, payload и угол поворота.
7. В консоли CanMV IDE будет выводиться строка вида:

```text
payload "Hi, Yahboom", rotation 3.000 degrees
```

## Как работает распознавание Data Matrix

Основная функция:

```python
matrices = img.find_datamatrices()
```

Она возвращает список найденных Data Matrix объектов. Для каждого найденного кода используются:

```python
matrix.rect()       # (x, y, w, h), рамка кода
matrix.payload()    # распознанный текст
matrix.rotation()   # угол поворота в радианах
```

Рамка рисуется так:

```python
img.draw_rectangle(matrix.rect(), color=(255, 0, 0), thickness=4)
```

Payload и угол поворота выводятся так:

```python
rotation = (180.0 * matrix.rotation()) / math.pi
img.draw_string_advanced(x, y, 20, "%s [%.2f] deg" % (payload, rotation), color=(255, 0, 0))
```

## DM code и QR code

DM code и QR code оба являются двумерными кодами, но применяются немного по-разному:

| Параметр | DM code / Data Matrix | QR code |
| --- | --- | --- |
| Внешний вид | Сплошная L-образная граница | Три большие позиционные метки |
| Размер | Может быть очень маленьким | Обычно требует большего размера |
| Применение | Промышленная маркировка, мелкие детали | Ссылки, платежи, маркетинг, общие данные |
| Устойчивость | Может читаться при частичном повреждении | Тоже имеет коррекцию ошибок |

В PDF отмечено, что успешность распознавания DM может быть ниже, чем у QR-кода. Если код не распознается, попробуйте повернуть сам код или камеру.

## ROI: ускорение поиска

По умолчанию пример ищет Data Matrix по всему кадру:

```python
DMCODE_ROI = None
```

Для ускорения можно ограничить область поиска:

```python
DMCODE_ROI = (160, 80, 320, 320)
```

ROI имеет формат:

```python
(x, y, w, h)
```

Если DM code всегда находится в центре кадра, ROI может повысить FPS.

## Пример с UART

Файл `02_dmcode_uart.py` отправляет данные через Yahboom protocol:

```python
pto_data = pto.get_dmcode_data(x, y, w, h, payload, rotation)
uart.send(pto_data)
```

UART инициализируется так:

```python
uart = YbUart(baudrate=115200)
```

Если в прошивке нет библиотек `libs.YbProtocol` или `ybUtils.YbUart`, пример не падает, а отключает UART и продолжает распознавание на экране.

## Чтение файлов на K230

Файл `03_dmcode_file_io.py` показывает чтение настроек из текстового файла.

Имя файла:

```text
dmcode_config.txt
```

Пример содержимого:

```text
# K230 Data Matrix / DM Code Recognition config
USE_ROI=0
ROI=160,80,320,320
```

Чтение файла:

```python
with open("/sdcard/dmcode_config.txt", "r") as f:
    text = f.read()
```

Разбор строки:

```python
key, value = line.split("=", 1)
```

Разбор ROI:

```python
parts = value.replace(" ", "").split(",")
roi = tuple([int(v) for v in parts])
```

На CanMV/K230 относительный путь иногда недоступен для записи при запуске из IDE. Поэтому пример сначала ищет доступную папку:

```python
FILE_DIR_CANDIDATES = ["/sdcard", "/data", "/flash", "/"]
```

Если файловая система недоступна для записи, пример продолжает работать со значениями по умолчанию.

## Запись файлов на K230

Запись выполняется через `open(..., "w")`:

```python
with open("/sdcard/dmcode_result.txt", "w") as f:
    f.write("payload=Hi, Yahboom\n")
```

Режимы открытия:

| Режим | Что делает |
| --- | --- |
| `"r"` | Чтение существующего файла. |
| `"w"` | Запись с заменой старого содержимого. Если файла нет, он будет создан. |
| `"a"` | Добавление текста в конец файла. |

Файл результата `dmcode_result.txt` обновляется при распознавании:

```text
time_ms=123456
fps=28.500
payload=Hi, Yahboom
rotation_deg=3.000
x=190
y=120
w=180
h=180
```

Почему не записывать каждый кадр: один и тот же DM code может распознаваться много раз подряд, поэтому в примере есть ограничение частоты записи.

## Рекомендации для хорошего распознавания

1. Держите DM code в фокусе.
2. Используйте хороший контраст: черный код на белом фоне.
3. Уберите блики с экрана или бумаги.
4. Разместите код крупно в кадре.
5. Если код не читается, попробуйте повернуть код или камеру.
6. Используйте ROI, если код всегда появляется в одной области кадра.
7. Попробуйте режим `Sensor.GRAYSCALE`, если RGB565 работает нестабильно в ваших условиях.
